# Suzu-3 放量续训评测（第三轮 c)、d)）

> 命名说明（2026-10-19）：版本号规则改为 主版本.次版本，主版本只在结构、词表变化或从零训练时递增。本报告里的 Suzu-3 是同结构续训版，正式名称为 Suzu-2.1；文件名保留以免打断历史链接。

日期 2026-10-19。Suzu-3 是在 Suzu-2 权重上续训得到的，不是从零训练。结构与 Suzu-2 相同（12 层、512 维、8 头，40.9M 参数），Q8_0 体积 43.9 MB，字符词表与 Suzu-2 完全一致，所以现有的 GGUF 加载、词表映射和手机、桌面推理端都不用改。

## 训练设定

- 教师：Qwen3.5-4B-Base（nf4）标注；二次元与技术题在上文前加领域提示句（提示不参与评分），日常口语和维基不加。
- 题：14 万道，维基 10 万、日常口语 2 万、技术 1.2 万、二次元 8000；难例约占四分之三。
- 句子：维基约 93.6 万句加合成领域语料，按 维基80 / 日常10 / 技术6 / 二次元4 采样；领域句基本只用一遍，重复 1.1 到 1.3 次（试点二是约 3 倍）。
- 超参：与试点二相同（学习率 1e-4，15000 步，其余沿用第二轮），取末步检查点（开发集上也是最优）。
- 合成语料：Qwen3.5-9B 生成，经繁转简、长度、字符白名单、去重、近重复、与 tests/domain 和 tests/holdout 的泄漏过滤，再用 4B-Base 困惑度丢掉最差的一部分。最终日常口语 117017、技术 52967、二次元 43850 句（二次元丢弃 4.5%）。生成参数与提示词见 DATA.md。

## 名字幻觉与术语（抽查，不含个人数据）

- 二次元：提示里要求只用广为人知的作品与角色、拿不准用通用称呼。抽查 16 句新加回的句子没有看到编造的作品名或角色名。困惑度丢弃比例从 10% 降到 4.5% 后，圈内用语保留更多（吧唧 519→625，谷子 377→412，补番 327→361，本命 75→84）。
- 技术：抽查个别术语拼写错（例如把 React 写成 Reax）和重字（依赖依赖升级），比例很低，没有加术语表校正。

## 局限

- 新留出题是手写的，后加的一批难词取自训练语料词表（句子是新写的，不与训练句重叠），可能比完全独立的词略有利；词频表是用维基、jieba 词典加合成语料补全的，两个模型共用同一张表，所以比较仍然公平，但绝对数字不能与第二轮报告直接对照。
- 续训而非从零：续训是否已经饱和，还需要一次从零训练的对照。
- 领域题为合成句子，不代表真实输入。
